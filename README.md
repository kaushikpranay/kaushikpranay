# flagship_project.ts

## Self-Improving RAG Infrastructure

Production-grade customer support system that improves over time using human feedback loops and adaptive retrieval.

```txt
User Query
    ↓
FastAPI Gateway
    ↓
LangGraph Router
    ↓
Retriever Layer
    ↓
pgvector Semantic Cache
    ↓
LLM Routing Layer
    ↓
Fallback + Retry Handler
    ↓
Final Response
```
