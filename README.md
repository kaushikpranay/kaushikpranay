## 🚀 Featured Project — Self-Improving RAG System

> **Live → [rag-system.ddns.net](https://rag-system.ddns.net/)**

A production-grade customer support system that gets smarter over time through human-in-the-loop feedback.

| Problem | What I Built | Result |
|---|---|---|
| 0% accuracy on unseen domains | Human-in-the-loop learning + verified semantic embeddings | **0% → 85% accuracy** in one week |
| Inconsistent LLM responses | 3-stage adaptive retry pipeline with dynamic retrieval tuning | **15% improvement** in answer consistency |
| Repeated manual query handling | Semantic caching via pgvector similarity search | **90% reduction** in manual effort |
| Traffic spike failures | Load balancing + LLM failover routing | High availability, low latency |

**Stack:** Python · LangGraph · FastAPI · AWS (S3, RDS, DynamoDB, SQS, EC2, Bedrock) · pgvector · Llama 3 (Groq)
